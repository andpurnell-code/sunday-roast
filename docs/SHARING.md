# Sharing

The full report is private and never shared automatically. The Share button creates a separate, share-safe version.

## What the share version contains
Built from an allowlist: the headline, a few highlights and the Chef verdict. It never contains colleague names or quotes, customer or confidential detail, sensitive categories (hiring, pay, performance, health, leave, legal), or internal URLs. A leak check runs and blocks the export if it finds a problem.

## How to share
1. Click **Share** and pick what to include.
2. Read the preview. It is exactly what will leave.
3. Tick the review box.
4. **Copy text**, **Copy image**, or **Share on LinkedIn**.

LinkedIn opens its post composer in a new tab, prefilled with the text. You press Post yourself. Nothing is posted for you.

## Known limits
- The LinkedIn prefill link is not a documented, supported LinkedIn API and may change. Copy text always works.
- A link cannot attach an image. Use Copy image, then paste it into the composer.
- There is no public page or link preview. A hosted link is created only if you ask for one and confirm the payload.
- Revoking a hosted page means deleting it. Expiry is not supported and not promised.
