# Code of Conduct

Be kind. This project is about reflecting on your own work with humour, not about mocking people.

- Jokes in contributions must never target colleagues, protected characteristics, health, family or private circumstances.
- No contributions that turn the Roast into a tool for monitoring, ranking or scoring other people.
- Be constructive in reviews and issues. Assume good faith.

Report problems by opening an issue or emailing the maintainer through the address on the GitHub profile. Maintainers may remove content and block contributors who break these rules. This text is adapted in spirit from the Contributor Covenant 2.1.
