# Changelog

## 1.0.0 - 2026-11-01
First public release.
- Five-stage pipeline (discovery, reconstruction, interpretation, editorial, presentation) with persisted JSON per stage.
- 20 selectable sources, read-only, own activity only.
- Report page, Chef voice with lint rules, allowlisted share flow with leak check, LinkedIn composer link.
- Optional user notes ("anything Chef can't see?") and opt-in open loops.
- Claude.ai zip, Claude Code plugin and marketplace manifest.
- LinkedIn is not a source. "Roast My LinkedIn" is a separate, future product.
