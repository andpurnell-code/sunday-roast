# Contributing

Thanks for helping. The one rule: **the facts are sacred**. Changes must not make the skill invent evidence, read unselected sources, or leak colleague detail.

## Setup
No dependencies. Python 3.9+.

```
python3 plugins/sunday-roast/skills/sunday-roast/tests/run_tests.py
python3 tools/verify_release.py
```

The DOM test (`tests/dom_test.js`) needs `jsdom` (`npm i jsdom`) and is skipped otherwise.

## Where things live
The canonical skill is `plugins/sunday-roast/skills/sunday-roast/`. There is no second copy. `dist/sunday-roast-skill.zip` is generated by `python3 tools/package.py`, so rebuild it in the same commit.

## Good contributions
- Source playbooks (`templates/sources.json` and `sources.md`), including caveats from real use.
- Linter rules and tests for the voice.
- Bug fixes with a failing test first.
- Docs.

## Please avoid
- New network calls. Anything that posts, edits or sends.
- Frontmatter keys other than name, description, license, compatibility, metadata and allowed-tools (claude.ai rejects others).
- Jokes about people, health, or private life. Real data in fixtures: use fictional personas only.
- Adding third-party art or fonts without confirming the licence in the PR.

## PRs
Describe what changed and how you tested it. Update CHANGELOG.md. Keep the SKILL.md description under 1024 characters.
